# Oasis Infobyte Internship — Web Development & Designing (Level 3)

Web development & designing internship builds for **Oasis Infobyte**.

## 🍕 WebDev L3: Pizza Delivery App

A full-stack pizza delivery application with real-time order tracking.

### Features
- Full menu with cart and checkout flow
- **Razorpay** payment integration
- **Socket.io** real-time order tracking
- JWT-based customer authentication
- **30 API tests + 4 socket tests, all passing**

### Structure
```
WebDev-L3-PizzaDelivery/
├── client/    # React frontend
├── server/    # Node.js + Express API
└── tests/     # API + socket tests
```

## 🛠️ Tech
`React` `Node.js` `Express` `MongoDB` `Razorpay` `Socket.io` `JWT` `Mocha/Chai`
